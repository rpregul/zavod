# Нейро-зарядка

Утренняя зарядка для мозга вместо рилсов. Открыл сайт, 5 минут упражнений, результат в графике.

**Адрес:** `/neuro/` (например, plotnikovprod.ru/neuro/)

## Упражнения (каждое по 1 минуте)

1. **Шульте 1 → 25.** Смотришь в подсвеченный центр, находишь числа по порядку. Счёт = сколько чисел нашёл. Закончил таблицу раньше: выдаётся новая, счёт продолжается.
2. **Шульте вверх ногами 25 → 1.** Таблица повёрнута на 180°, числа идут в обратном порядке.
3. **Dobble.** 55 карточек по 8 рисунков, у любых двух ровно один общий (та же математика, что в настоящей игре). Находишь общий рисунок на твоей и общей карте, общая карта ложится на твою, открывается следующая. Счёт = найденные пары.
4. **Запоминание слов.** 3 столбика по 10 слов, минуту смотришь и строишь цепочку образов. Потом минуту записываешь. Засчитываются только точные слова (регистр и ё/е не важны). Слова с ошибкой в окончании помечаются «почти» и показывается, где ошибка.

## Вход

Имя + PIN из 4 цифр, без почты и паролей. Устройство запоминает вход.

## Где хранятся данные

- Пока облако не подключено: в браузере на устройстве.
- После подключения (`js/config.js`, инструкция в `supabase/README.md`): в общей базе, историю видно с любого телефона по тому же имени и PIN. Результаты, накопленные до подключения, автоматически загрузятся в облако.

| `js/charts.js` | графики и календарь |
